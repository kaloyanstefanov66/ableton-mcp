# Vinnie Paul (Pantera)

Read with `genres/groove-metal.md`.

**Feel:** groove first, huge and swaggering. The kick locks to riffs with double-kick bursts
(often triplets), the snare is massive and simple, and swung shuffles bounce.
**Tempo range:** 90–150 BPM (groove), some faster thrashy sections.

## Vocabulary
- Kick doubles the riff exactly, including fast triplet double-kick runs.
- Half-time stomps with crash or china quarters.
- Shuffled grooves (triplet hats/ride) with a heavy backbeat.
- Very few ghost notes. Every hit is big.
- Cymbal chokes and dead stops with the band.

## Grooves
### Riff-locked stomp
```
C  x...|x...|x...|x...
S  ....|X...|....|X...
K  xxx.|x...|xxx.|x...      triplet-ish kick bursts following the riff
```
### Shuffle (triplets)
```
R  x.xx.xx.xx.x
S  ...X.....X..
K  x.x.....x.x.
```
### Half-time breakdown
```
N  x...|x...|x...|x...
S  ....|....|X...|....
K  x.xx|xx..|x.xx|xx..
```

## Fills
Short, heavy two-beat fills (floor-tom and snare flams, kick-triplet pickups), then a choke or a crash.

## Humanize
Velocity ±5 at very high levels (kick 118, snare 125). Timing ±6 ms, slightly behind on snare in shuffles.
