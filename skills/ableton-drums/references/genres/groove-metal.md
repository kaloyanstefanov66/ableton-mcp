# Groove metal (Pantera, Lamb of God, Sepultura's groove era, Machine Head)

**Tempo / feel:** 90–150 BPM, mid-tempo and heavy, often with a swung or shuffled bounce.
The kick follows the riff almost note-for-note; the snare stays big and simple.
**Timekeeper:** china or crash quarters in heavy parts, hats or ride in verses, cymbal chokes.
**Kit:** Acuff Kit.

## Grooves
### Riff-locked groove
```
N  x...|x...|x...|x...
S  ....|X...|....|X...
K  xx.x|..xx|.x.x|x...      copy the riff's chug rhythm
```
### Half-time stomp
```
C  x...|x...|x...|x...
S  ....|....|X...|....
K  x.xx|x...|..xx|x.x.
```
### Shuffle / bounce (triplets: 12 steps per bar)
```
H  x.xx.xx.xx.x
S  ...X.....X..
K  x.x..xx.x...
```
### Double-kick triplet run under a riff (triplets)
```
C  x..x..x..x..
S  ...X.....X..
K  xxxxxxxxxxxx
```

## Fills
Short, punchy fills: two-beat tom descents, snare flams, triplet kick bursts. End phrases with
a choke (crash, then silence for an 8th).

## Dynamics
Snare 120+, kick 110–125, cymbals loud. Grooves come from placement, not ghost notes.

## Signature moves
Swung heaviness, kick mirroring the riff, stops and pickups with the band, a single huge crash after a gap.
