# Thrash metal (Metallica, Slayer, Megadeth, Anthrax)

**Tempo / feel:** 160–250 BPM. Driving and aggressive, built on the "skank" beat and the gallop.
**Timekeeper:** crash or hats on 8ths/quarters; ride for verses at extreme tempos.
**Kit:** Acuff Kit.

## Grooves
### Skank / thrash beat (fast verses)
```
H  x.x.|x.x.|x.x.|x.x.      or C on quarters for intensity
S  ..X.|..X.|..X.|..X.
K  x...|x...|x...|x...
```
### Gallop (follows galloping riffs: 8th + two 16ths)
```
C  x...|x...|x...|x...
S  ....|X...|....|X...
K  x.xx|x.xx|x.xx|x.xx
```
### Mid-tempo chug (100–140)
```
H  x.x.|x.x.|x.x.|x.x.
S  ....|X...|....|X...
K  x.xx|..x.|x.xx|..x.
```
### Double-bass section
```
C  x...|x...|x...|x...
S  ....|X...|....|X...
K  xxxx|xxxx|xxxx|xxxx
```

## Fills
Snare 16th rolls, quick tom descents in 16ths, unison stops with the band, crash chokes.

## Dynamics
Everything 105–127. Hats 90+. Few ghost notes.

## Signature moves
Gallop kick under galloping riffs, crash on every quarter in climaxes, stop-start hits with the riff.
