# Rock / hard rock / alt-rock

**Tempo / feel:** 100–160 BPM, straight 8ths, a solid backbeat.
**Timekeeper:** 8th hats in verses, ride or open hats in choruses, crash on section starts.
**Kit:** Gen Purpose, Dry Session, Acuff (harder rock).

## Grooves
### Verse
```
H  x.o.|x.o.|x.o.|x.o.
S  ....|X...|....|X...
K  x...|..x.|x.x.|....
```
### Chorus
```
O  x.x.|x.x.|x.x.|x.x.      or R x.x. ride
C  x...|....|....|....      crash on bar 1 of each phrase
S  ....|X...|....|X...
K  x...|..x.|x.x.|..x.
```
### Four-on-the-floor lift
```
H  x.x.|x.x.|x.x.|x.x.
S  ....|X...|....|X...
K  x...|x...|x...|x...
```

## Fills
Every 4 or 8 bars on beat 4. Use 16th snare, snare→toms, or 8th-note triplet tom runs.
Crash + kick on the next downbeat.

## Dynamics
Backbeat 110–120, hats 70–95 with beat accents, kick 100–115.

## Signature moves
Pushes: crash and kick on the "and" of 4 that anticipate the downbeat, with the guitar.
Half-bar stops before the last chorus.
